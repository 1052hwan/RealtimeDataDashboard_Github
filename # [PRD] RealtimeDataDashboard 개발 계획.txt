# [PRD] RealtimeDataDashboard 개발 계획서

## 1. 프로젝트 개요
- **프로젝트명**: RealtimeDataDashboard
- **목적**: Supabase에 10분 간격으로 동기화되는 관측소 데이터를 모바일에서 실시간 모니터링하고, 데이터 품질(QC) 및 시계열 분석 기능을 제공함.
- **대상 사용자**: 관측소 데이터 관리자 및 현장 점검 요원

## 2. 주요 목표 (Goals)
- **실시간성 확보**: 10분 주기로 업데이트되는 데이터의 최신 상태 유지.
- **가변적 스키마 대응**: 지점별로 상이한 데이터 구조(Header)를 유연하게 처리.
- **데이터 신뢰성 검증**: QC 알고리즘을 통한 오측치 식별 및 시각화.
- **사용자 경험(UX) 최적화**: 모바일 환경에 최적화된 프리미엄 다크 모드 UI/UX 구현.

## 3. 핵심 기능 (Functional Requirements)

### 3.1. 대시보드 및 상태 모니터링
- **수집 상태 요약**: 현재 데이터 수집의 정상/지연/오류 상태를 인디케이터로 표시.
- **최신 관측치 카드**: 가장 최근 수집된 주요 변수(유속, 수위 등)를 카드 형태로 노출.

### 3.2. 시계열 데이터 시각화
- **인터랙티브 차트**: 지점별 변수에 따른 시계열 그래프(Line Chart) 제공.
- **멀티 포인트 지원**: 터치 시 해당 시점의 상세 값 팝업 노출.

### 3.3. 데이터 품질 관리 (QC)
- **이상치 탐지**: 급격한 변동이나 물리적 범위를 벗어난 데이터를 색상으로 구분(예: Red/Yellow).
- **오측 사항 리스트**: QC 필터링을 통과하지 못한 레코드를 별도 목록으로 제공.

### 3.4. 데이터 조회 및 필터링
- **시간대 설정**: 시작/종료 날짜 및 시간 선택을 통한 과거 데이터 조회.
- **지점 선택**: 수파베이스의 테이블 목록을 동적으로 불러와 관측 지점 전환.

## 4. 기술 스택 및 연계 방안 (Technical Stack)

| 구분 | 기술 스택 | 비고 |
| :--- | :--- | :--- |
| **Frontend** | Vite + React / Next.js | 빠른 로딩과 모바일 반응형 구현 |
| **Styling** | Vanilla CSS + CSS Variables | 프리미엄 다크 모드 및 애니메이션 |
| **Database** | Supabase (PostgreSQL) | 기존 데이터베이스 연동 |
| **Library** | Lucide React (Icons), Recharts / Chart.js | 시각화 도구 |
| **Auth** | Supabase Auth | 보안 로그인 (필요 시) |

### 데이터 연계 아키텍처
- **Dynamic Schema Fetching**: 지점별로 테이블이 늘어나는 구조이므로, `supabase.rpc()` 또는 메타데이터 테이블을 참조하여 동적으로 테이블 리스트를 로드함.
- **Realtime Subscription**: Supabase Realtime 기능을 사용하여 DB 변경 시 대시보드 즉시 갱신.

## 5. UI/UX 디자인 가이드라인

- **테마**: 심해의 정적을 느낄 수 있는 **Deep Charcoal & Neon Blue** 다크 테마.
- **레이아웃**: 한 손 조작이 용이하도록 주요 버튼 및 필터를 하단에 배치(Bottom Sheet 활용).
- **마이크로 애니메이션**: 데이터 로딩 시 Skeleton Screen 적용 및 차트 진입 시 부드러운 페이드인 효과.

## 6. 품질 및 성능 요구사항
- **응답 속도**: 데이터 쿼리 후 시각화까지 1.5초 이내 완료.
- **SEO**: 기본적인 Meta Tag 및 시맨틱 태그 적용.
- **오류 처리**: 네트워크 단절 시 '오프라인 모드' 안내 및 재연결 시도.
